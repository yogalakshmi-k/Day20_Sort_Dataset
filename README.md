# Veda Technology Internship – Sort Dataset

## 📌 Project Overview
This project demonstrates how to sort datasets using Python and the Pandas library. It is completed as part of the Veda Technology Internship.

## 🎯 Objective
To understand how sorting helps organize and analyze datasets using ascending and descending order.

## 🛠️ Tools and Technologies
- Python
- Pandas
- Google Colab
- GitHub

## 📊 Dataset
A sample Student Performance Dataset containing the following columns:
- Student
- Age
- Marks
- Department

## ✅ Tasks Completed
1. Created a Student Performance Dataset using Pandas.
2. Sorted student marks in ascending order.
3. Sorted student marks in descending order.
4. Sorted data using multiple columns.
5. Sorted students by age.
6. Displayed the top three students based on marks.

## 💻 Python Concepts Used
- Pandas DataFrame
- `sort_values()`
- Ascending and descending sorting
- Multiple-column sorting
- `head()` function

## ▶️ How to Run
1. Open Google Colab.
2. Upload the `.ipynb` notebook or paste the Python code into a code cell.
3. Run the code cells.
4. View the sorted dataset outputs.

## 📌 Conclusion
This project demonstrates how Pandas sorting functions can organize student data efficiently and make data analysis easier.
